Segùn los requerimientos funcionales se debe de realizar un CRUD para la informacion del trabajador

## Requerimientos Funcionales

**RF-02**: El sistema deberá listar los empleados registrados.

**RF-03**: El sistema deberá permitir la búsqueda de un empleado mediante su identificación.

**RF-04**: El sistema deberá actualizar los datos de un empleado dado su identificador único.

**RF-05**: El sistema deberá eliminar un empleado dado su identificador único.
